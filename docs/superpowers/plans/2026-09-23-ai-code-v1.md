# AI Code V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a publishable Vue 3 npm package that installs Cursor rules and skills in one command and executes real quality checks.

**Architecture:** Tool-neutral Markdown sources in `content/`; Cursor projection in `src/adapters/cursor.mjs`; project detection and conflict handling in `src/project.mjs`; check runner in `src/check.mjs`; CLI in `bin/ai-code.mjs`.

**Tech Stack:** Node.js ESM, node:test, npm; zero runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-09-23-ai-code-v1-design.md`

## Global Constraints

- Package `@agent-xy/ai-code`, MIT, public npm, Cursor V1, future Codex adapter.
- Do not overwrite non-managed project files or existing quality configuration.
- Default observe mode; real script failures block and missing checks never pass.
