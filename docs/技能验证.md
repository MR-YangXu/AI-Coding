# 技能验证

用于维护 `content/` 中的基础规则和专项技能。程序测试验证分发与检查机制；场景评估验证 AI 的实际决策，两者分别记录。

## 本轮修改与场景复核

以下是规则的静态复核结果，不代表已通过真实模型行为测试。每次技能修改只选择相关场景验证。

| 场景与任务 | 提供的上下文 | 修改后的规则与观察点 |
| --- | --- | --- |
| 修复连续搜索显示旧结果 | 请求入口、查询触发代码、现有取消或序号机制 | API 与 Hook 明确只有最新有效查询更新结果、错误和加载状态；验证旧请求晚成功、晚失败及结束，不能覆盖新结果或提前结束加载。 |
| 接入列表，响应格式不明确 | 请求封装、拦截器、已有调用方；明确哪些契约未知 | 先查证成功判定和解包层级；剩余关键项须确认，不能猜 `list`/`data` 或用空数组掩盖失败。 |
| 给订单状态增加展示文案 | 原始响应类型、页面、已有格式化函数 | 原始字段与传输契约保留；展示转换遵循现有边界，无既有边界时靠近消费方，不因字段命名偏好新增映射层。 |
| 修改较大页面中的一个筛选条件 | 完整页面及相关请求入口 | 按职责和实际复用判断拆分；不能仅凭行数抽空页面、提升全局状态或重构无关部分。 |
| 修改 SCSS 项目的按钮样式 | 相邻组件、主题变量与构建配置 | 组件技能明确沿用现有样式方案；观察是否复用变量、限制样式影响范围，且没有迁移到 Less。 |
| 只审查一个组件 | 改动差异、调用方及组件约定 | 描述覆盖审查任务；输出可定位的问题、触发条件与影响，工作区不产生修复改动。 |
| 接入文件上传 | 现有上传组件、接口参数、文件限制与取消能力 | 限制来自契约，不编造阈值；检查有效文件、超限、不支持的类型、失败与取消，取消不能显示成功。 |
| 修复导出时保存错误文件 | 正常文件响应、HTTP 200 的错误 JSON/HTML、下载契约 | 按契约识别文件与错误；仅凭 HTTP 200 或 Blob 类型不足以确认成功，合法 JSON/HTML 下载也不能一律拒绝。 |
| 修复登录后的回跳 | 路由表、守卫、允许的回跳范围与安全入口 | 检查缺失值、多值参数、非法格式及外部目标，包括 `//example.com`；不把未验证输入直接用于跳转。 |
| 接入用户可编辑内容 | 内容来源、已有 HTML 净化方案、表单和日志入口 | 用户可控 HTML 按既有边界处理，缺失方案时不能直接注入；检查标签与键盘操作，日志不包含敏感信息。 |
| admin：参考成熟页面新增头像卡片页 | 设计图、目标项目搜索与上传能力、主题入口、参考页面；接口尚未提供 | 先确认交付范围和复用清单，明确配置、类型、样式与卡片组件的职责；范例中的 Hook 不存在时不生成引用，模拟数据隔离，不编造库存口径或接口。 |
| admin：新建标准后台表格页 | 已有搜索、表格、分页 Hook、确认接口和相邻页面 | 配置有独立落点，页面连接已有能力；查询默认值按实例隔离，搜索、重置与再次进入结果一致，不重复实现公共流程。 |
| admin：给列表新增详情抽屉 | 现有抽屉外壳、列表与详情契约、相邻私有详情组件 | 复用外壳并提取私有面板，页面保留适当的请求与状态编排；快速打开不同对象时旧响应不覆盖当前详情，失败状态可观察。 |
| 梳理项目推荐入口 | 当前仓库组件、调用方、团队选择的范例与场景范围 | profile 记录适用范围、用途、源码入口和可借鉴部分；路径经过核实，不复制第二份组件契约或质量命令，H5 不默认使用后台范例。 |
| 声称已有组件不适用 | 原始需求、候选组件及其调用方 | 不复用说明指出源码中的具体缺口，并评估配置、插槽或兼容扩展；不凭组件名称、缺少调用示例或“贴近设计稿”作决定。 |
| 修复缺失或失效的类型检查 | package 脚本、应用与构建类型配置、脚本映射及现有错误 | 区分配置和代码问题，保留检查范围，显式更新映射；不假设 sync 自动发现命令，不用构建通过代替类型检查结果。 |
| admin：验收头像库交互 | 已确认交互策略、可运行页面、受控失败响应与图片资源 | 按操作/预期表检查搜索、重置、标签、启停、图片失败和统计；输出实际观察，区分模拟验证与真实联调，未运行不写成通过。 |
| 查询或新增业务常量 | 公共导出、当前业务定义与调用方 | 先查公共再查业务，追踪相关实际定义；新增前检索同义定义，不把公共与业务相同含义的枚举各维护一份。 |
| 连续追问同一常量 | 已读取的定义及其是否变化 | 复用已核实且未变化的内容，范围或内容变化时才补读，不每轮全文加载全项目常量。 |
| 复制或改名重建状态字典 | 权威定义、复制文件与接口契约 | 同义重复定义禁止；转导出和别名允许，不把不同业务相同数字误当作同义。程序确定违规与疑似重复分别报告。 |
| H5 页面使用国际化动态字典 | API、字典加载能力与语言入口 | 动态选项不复制为静态枚举，翻译在响应式上下文中生成，不套用后台组件配置。 |

## 实际行为评估方法

1. 在隔离的项目副本中准备场景所需源码、配置和最小复现。修改前后使用相同的任务、项目基线、模型与设置，各开一个无历史上下文的会话。
2. 让待评估版本按正常方式加载基础规则与相关技能。只提供任务和原始材料，不提前提供上表的预期答案。
3. 保存实际读取的技能、输出、代码差异与检查结果。实现任务验证业务行为；审查任务验证问题证据和工作区是否被修改。
4. 记录改善、回归或无法判断及其证据。没有实际运行的场景标为“未运行”；不通过匹配回答措辞来判定成功，也不将单次成功视为稳定性证明。

## 工程验证

- 使用 Node.js 18+ 运行 `npm test`，覆盖初始化、场景选择与切换、同步、冲突保护、打包安装与质量检查。
- 运行 `npm pack --dry-run --json`，确认基础规则、八个通用技能和两个可选场景技能均进入包；项目安装时只生成所选场景。
- 确认 `content/templates/` 下的通用 Vue、admin、H5 三份 profile 模板随包分发，可按 README 复制为项目约定；模板不进入自动生成的 Cursor 技能，填写后的 profile 在 `sync` 后保持原样。
- 验证 `content/templates/constants/` 的公共定义、业务定义、Vue 用例和配置片段随包分发；使用真实 TypeScript/Vue 解析器验证示例，选项值保持契约类型。
- 常量检查测试覆盖硬编码、重复定义、疑似改名复制、来源校验、字典完整性、观察/阻断模式、未配置/未完成、输出截断及只读行为；原有增量诊断仍由项目 ESLint 执行。
- 校验技能 YAML 元信息中的名称和描述，并检查本地参考链接；新增参考资料时，还须验证安装后的文件和同步行为。
- 运行 `git diff --check`。命令失败、缺失或未执行须分别记录，不能推断为通过。

## 场景选择验证

`test/scenarios.test.mjs` 验证 CLI 行为，包括通用、管理后台、移动端和混合选择，非交互默认值、交互选择与输入取消，旧配置兼容、重复初始化、配置漂移、场景切换及手改/冲突/符号链接保护。打包安装测试验证两个可选场景可从 npm 包生成到项目。

场景内容的实际模型评估补充以下任务：

| 任务 | 观察点 |
| --- | --- |
| 后台表格增加跨页批量操作 | 先确认选择范围与接口契约，正确处理部分成功，不盲目重试已成功项。 |
| 仅通用 Vue：修改一个交互展示页 | 保留通用数据流、类型与异步清理要求，按实际复杂度组织代码，不生成搜索列配置、后台详情抽屉或分页 Hook 引用。 |
| H5 表单修复软键盘遮挡提交按钮 | 沿用现有适配方式，检查焦点、可见区域与安全区，并如实说明设备验证范围。 |
| 仅 H5：给商品列表增加关键词筛选 | 使用移动端组件与加载方式，不因出现“搜索”“列表”而套用后台模板；本次改动仍遵守通用状态隔离和异步交互要求。 |
| 混合项目修改桌面列表 | 可读取后台场景，不能仅因启用了 H5 场景而迁移桌面布局或增加触摸框架。 |
| 混合项目修改移动商品详情 | 使用通用与 H5 技能，后台技能已安装不意味着必须读取或应用；不引入后台配置目录、表格或管理权限模型。 |
| 混合项目修改移动管理功能 | 当前功能确属后台且面向移动端时，可组合后台业务要求与 H5 环境要求；两个场景均不扩散到无关页面。 |

分发采用基础规则、八个通用技能及两个可选场景技能。真实模型的修改前后对照尚未运行；场景表用于复核规则覆盖并为后续实测提供验收依据。

## 通用能力与场景边界的验收范围

本轮将页面文件树、成组搜索与列配置、后台列表 Hook 示例、头像卡片和详情抽屉范例集中到 `admin`。基础规则、页面、组件与 Hook 保留跨场景的数据流、类型、状态隔离、复用判断和副作用管理；H5 保留移动端交互要求。场景入口明确“已安装”与“当前任务适用”的区别。

工程验证覆盖 `none`、`admin`、`mobile-h5` 和混合选择的生成与同步：通用技能内容在四种选择中一致，只分发所选场景；从旧版规则同步时移除通用内容中的后台模板，并保留场景选择与项目自行维护的 `profile.md`。这验证分发与迁移边界，不通过匹配规则措辞来宣称 AI 行为正确。

头像卡片页、标准表格页和详情抽屉页的真实模型对照评估仍为“未运行”。规则静态复核与分发测试只能证明规范内容和安装行为，不能证明生成质量已经稳定提高；后续按上面的实际行为评估方法执行，不以回答措辞或文件数量作为通过条件。

## 项目约定、复用决策与验收流程

基础规则覆盖项目准备与每次开发的区别、源码可核对的不复用说明、类型检查接入和三类交付证据；组件与 Hook 补充各自契约的核对位置，页面技能明确实际行为验证方式。搜索、重置、标签、启停、图片失败与统计的操作/预期表只放在 admin 场景。

工程验证使用四种场景的临时项目，核对生成与升级同步结果、通用技能的一致性，以及项目 profile 和脚本映射不被覆盖。对新增类型检查脚本验证：未更新映射时仍报告 missing，显式接入后确实执行脚本，并分别报告失败和通过。以上验证 CLI 行为，不代表业务项目类型错误已修复或真实页面交互已经验收。
