# 异步任务、通信与服务拆分

适用：定时任务、内部事件、第三方 HTTP、SSE、WebSocket、消息队列、注册中心、gRPC。课程主题：第 92—94、97、140—145、152、172—174 章。

## 先按契约选择通信方式

| 需求 | 候选方案 | 先确认 |
| --- | --- | --- |
| 同进程模块通知 | EventEmitter | 事件是否允许进程退出丢失、监听异常如何处理 |
| 按时执行、延后或间隔执行 | `@nestjs/schedule` | 时区、重叠执行、重启补偿、多实例重复调度 |
| 请求外部 API 并等结果 | HttpModule 或既有客户端 | 总超时、取消、有限重试、服务配额 |
| 服务端单向持续推送 | SSE | 认证、断线续接、代理缓冲和资源清理 |
| 双向交互、聊天或协同 | WebSocket/Socket.IO | 协议兼容、房间授权、顺序与交付语义 |
| 异步削峰、跨进程任务 | 消息队列 | 持久化、确认、重试、死信、幂等 |
| 明确独立部署边界的同步调用 | RPC/gRPC | 契约版本、超时、服务发现、失败传播 |

单体足够时维持单体。Monorepo 只是代码组织，不能证明服务已经独立运行或通信。第 171 章也说明考试实战最终未使用服务间通信；不要按课程计划推断其已经验证分布式架构。

## 定时任务与事件

定时任务明确 cron 表达式的秒字段、时区和夏令时影响；命令/API 以所安装版本为准，包名是 `@nestjs/schedule`。多实例执行需要一个调度所有者、支持排他任务的队列，或带租期/失效机制的锁。任务本身仍应幂等，锁过期后不能假定旧执行者立即停止。

长任务记录运行状态、游标和失败原因，限制并发并定义重跑范围。进程内 EventEmitter 不提供持久化和跨进程可靠投递；不能把必须成功的账务或通知仅寄托于内存事件。

外部 HTTP 设置连接/请求期限，重试仅用于合适的失败且有上限和退避；非幂等操作重试需要幂等保证。用户可控制目标 URL 时校验协议、目标及重定向，防止访问内部资源。Observable（可观察流）转 Promise 时确定只需首个值还是等待完成，并确保超时和取消不会泄露订阅。

## SSE 与 WebSocket

SSE 是文本事件流，`data` 可以承载 JSON 字符串，不是原生任意二进制通道。使用正确响应类型、事件 ID、心跳和必要的续传机制。浏览器原生 EventSource 不能自由设置 Authorization 头，选择现有安全认证方式或支持对应请求方式的客户端，避免把长效凭证放到 URL。

客户端断开时关闭定时器、订阅与后台资源。SSE 与下载流不要套普通 JSON 响应拦截器。反向代理需检查缓冲和空闲超时。

Socket.IO 协议不等于裸 WebSocket，客户端与适配器必须匹配。手写握手/帧协议用于学习，不作为普通业务项目默认实现。使用 TLS 对应的安全连接，并校验连接身份和允许来源。

连接建立、加入房间、发送消息、读取历史、下载附件都分别校验身份及资源权限。房间名和客户端 `userId` 不是授权凭据；群成员从服务端查证。离群/冻结后终止相关访问，不能只限制下一次登录。

先约定消息 ID、确认、重发、去重和排序规则。需可靠历史时先持久化或使用有明确补偿的投递流程；断线重连通过游标补拉，避免把实时消息与历史查询重复追加。前端清理旧房间监听，离开页面关闭连接或正确释放共享订阅。多实例广播使用匹配的共享适配器；负载均衡、粘性会话需求按传输模式验证。

## 队列与服务发现

RabbitMQ 的 exchange（交换机）选择按路由契约判断：direct 精确键、topic 模式键、fanout 广播、headers 头匹配。配置队列/消息持久化、发布确认、消费者 prefetch（预取量）及处理后 ack（确认）。失败消息有限重试，无法处理的进入死信或隔离流程。

消息可能重复送达，消费者以业务键去重并与关键写入一致提交；不能在处理前确认后丢失任务，也不能无限重新入队造成热循环。

Etcd/Nacos 按现有平台选用，不默认同时引入。注册租期、心跳、摘除、监听重连和配置版本都要有失败策略。配置变化先验证再生效；服务发现地址变化不能让旧连接无限留存。部署平台已有发现和配置能力时评估复用。

gRPC 使用 `.proto` 作为协议契约，字段编号不能随意重用；验证跨语言整数、空值、默认值、错误码和 deadline（调用期限）。Nest 的 `send/emit` 与 `MessagePattern/EventPattern` 按请求响应和事件语义配对，不能只因方法名像本地调用就忽略网络失败。

验证：任务重入、进程重启、事件异常、消息重复与毒消息、断线恢复、跨房间越权、慢客户端、服务发现不可用、配置无效，以及契约版本不一致。
