# AI 编码基本规则

## 阅读预算

有 `.ai-code/profile.md` 时，它是唯一的项目入口。只读当前场景的推荐能力、源码入口、参考实现、可借鉴部分和禁止效仿项，再打开档案点名的一个路由模块、一个参考页面的前 120 行。组件或 Hook 的契约用搜索定位 props、emits 和一处调用，不整文件加载。档案不代替组件契约，导入和字段仍以当前仓库源码为准。

没有档案时，只读一个相邻路由模块和一个同类页面的前 120 行，交付时注明缺口。不为本次任务新建档案，也不去安装包里翻模板。不派子代理，不做全库探索，不读 `docs/`、`.ai-code/README.md`、事实索引或其他仓库的技能。本仓库只使用已安装的 `ai-code-*` 技能，不读取 `company-vue-*` 或其他规范全文。

技能全文只读一次，会话里已读过的不重复打开。下表决定读哪一份；各技能不再要求打开其他技能。

| 本次改动 | 只读 |
| --- | --- |
| 新建或修改后台页面 | `ai-code-admin`；同时改路由时再读 `ai-code-route` |
| 新建或修改其他 Vue 页面 | `ai-code-view`；同时改路由时再读 `ai-code-route` |
| 移动端 H5 的触摸、安全区、键盘、滚动或弱网 | 在页面技能之外再读 `ai-code-mobile-h5` |
| 新增或修改枚举、状态字面量或数据字典 | `ai-code-constant` |
| 新增或修改请求模块 | `ai-code-api` |
| 提取或修改共享组件、组合式函数、Store、国际化 | 对应的 component、hook、state、i18n 技能 |

局部修复只读被改文件和它的直接调用约定，不按上表补读场景技能。仅要求审查时，报告有证据的问题、位置、触发条件和影响，不改代码。

## 实现约束

- 以需求的目标、范围和验收标准为准。关键事实无法确认时标明待确认项，继续完成不依赖它的工作。不编造仓库中不存在的模块、API、依赖或字段。
- 优先复用档案或相邻实现中的组件、请求层和工具。不复用时说明候选路径和具体缺口；“更简单”或“更贴近设计稿”不能作为理由。无既有先例不新增依赖。
- 同一业务语义只有一份常量和字典，使用处导入。页面配置不重新定义枚举。只在本次改动新增或修改码值时才读常量技能，并按“公共导出 → 当前业务入口 → 相关定义”检索；已核实且未变化的内容不重读。
- 只改任务范围。不顺手重构，不用 `any`、`@ts-ignore`、空 catch 或关闭检查来掩盖问题。
- 异步交互在代码里闭合 loading、空结果、失败、重复提交和过期响应。接口未定时使用隔离的演示数据，交付时标明未联调；只改内存不能写成保存成功。
- 页面持有本功能的查询和操作状态。请求类型留在 API 层，跨路由共享才进 Store，私有展示放同域组件。需要独立维护或被多个文件使用时再拆文件。

## 验收预算

- 默认只对本次改动文件运行项目已有的 lint。输出只留摘要；失败时只看报错位置。同一命令失败后修正一次再跑，不把完整日志读回对话。
- 类型检查只在改动含类型边界，并且能把范围限制在新文件时运行。仓库级类型检查、构建和全量测试不是页面任务的默认步骤。没跑或失败不能写成通过，也不用别的命令互相顶替。
- 行为只核对本次界面实际有的路径，每条一次：搜索与重置一致、筛选后回到第一页、末页删除回到有效页、启停失败回滚、非法上传被拒绝。看代码路径或做一次操作即可。不写浏览器脚本，不反复截图，不逐项手测刷新、返回和无权限，除非用户要求。
- 交付说明复用了哪一页、哪一个组件，以及 lint 的实际结果。未跑的类型检查和未联调的接口单独列出。

## 其他

- 不提交密钥、真实用户数据或含秘密的环境文件。日志和上报不输出令牌、完整 Cookie 或未脱敏个人信息。
- 类型检查脚本和 `.ai-code/config.json` 的映射，只在任务本身是修复检查时处理。历史类型错误不阻断无关改动，但交付保留失败状态。
- 涉及不可逆操作时先确认范围。
