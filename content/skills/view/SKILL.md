# 页面

先读相邻页面、布局、权限、表单和反馈模式，再写 UI。页面是业务编排层；涉及 API、路由、组件、Hook 或国际化时，同时读取对应技能。

## 开始前确定复用与结构

- 新建页面先检索当前仓库的布局、搜索、列表、上传、抽屉、公共 Hook 和主题入口，选一个最接近的可用范例。用户或项目指定了参考页面时，说明采用哪些组织方式，并核实对应能力在当前仓库存在。
- 简述复用清单与文件职责后直接实施；能力不匹配时说明具体缺口。不能因为截图中没有组件名称就从底层控件重写已有且满足需求的交互，也不能按参考仓库的 import 路径生成不存在的引用。
- 独立配置、类型、组件和样式的落点按下表及项目约定确定；已有局部改动保持最小范围，不为了目录齐全创建空文件或重构无关代码。

## 边界

- 页面持有业务查询条件、当前行、弹窗开关和局部操作状态，连接组件、API 与业务事件。已有分页、查询重置、选项加载或操作反馈 Hook 满足需求时优先调用，页面保留参数、结果适配和业务决策。
- 不要为缩短文件把整页状态抽成 Hook，或提升到全局 Store。
- 请求与原始响应类型留在 API 层；展示派生或纯转换沿用已有边界，没有既有边界时就近放在消费方，实际复用时才共享，不能改变传输契约。跨路由共享放 Store，页面私有 UI 放同域组件。

| 内容 | 放置与判断 |
| --- | --- |
| 页面入口 | `index.vue` 负责组件组装、状态连接、派生展示和业务事件编排；不同时堆积成组配置、演示数据、独立业务展示和大段样式。 |
| 页面配置 | 成组搜索项、默认查询、列表列配置和枚举放同域 `config.ts` 或 `config/`，沿用项目命名；只有配置规模或用途确实不同才继续拆分。少量局部常量可就近保留。 |
| 类型 | 接口参数和响应类型以领域 API 为源，页面直接引用或按项目惯例重导出；供配置、组件等共同使用的页面展示类型放同域 `types.ts`，不重复声明接口类型。 |
| 私有组件 | 具有独立展示、交互和样式职责的卡片、详情面板、表单、弹窗放同域组件目录，按组件技能定义输入和事件；不以单文件行数作为唯一拆分依据。 |
| 样式 | 沿用现有样式方案；样式较多或项目已约定分文件时，页面布局放同域样式文件，如 `index.scss`，由页面以原有作用域方式引入。组件自身样式跟随组件，复用主题变量。 |
| 演示数据 | 仅在交付范围允许时放独立 mock（模拟数据）文件或项目已有演示层，并按项目方式限制启用范围；不让示例数据默认进入正式业务路径。 |

配置中的可变对象按页面实例创建。查询初始值及动态选项使用工厂函数或项目已有克隆方式，不直接用 `reactive(共享配置对象)` 修改模块级默认值；查询状态与重置基准也不能共享可变引用。

## 编排

- 请求成功前不假设返回形状；按本项目响应层级更新列表、总数和详情。
- 搜索表单、列表展示与列表状态分别评估复用。卡片网格可复用搜索和分页能力，不必改变成表格；没有合适基建时按当前需求就近实现，不为单页另建通用框架。
- 模板避免复杂转换和多语句事件；用户可见文案走项目国际化入口。
- 接口缺失不妨碍先建立清晰的展示和组件边界，但不能编造端点、权限或字段契约。统计口径未确认时显式标为未提供或待确认，不将设计图中的示例数字写成业务结论。

## 异步与交互

- 每项异步闭合 loading，并处理空数据、失败、重复提交和过期响应。
- 详情弹窗和抽屉只接收所需最小数据，通过事件或约定方法与页面交互。
- 返回页面时的筛选、分页和滚动遵循项目既有模式，不要默默丢掉查询条件。
- 行内启停等写操作按项维护提交状态，避免重复触发；按项目策略在成功后更新数据，失败时保留原状态或回滚乐观更新，不能用仅修改内存冒充已保存。

## 文件上传（涉及时）

- 先复用已有上传组件，按项目契约在请求前检查大小、数量及允许的文件类型，失败时明确反馈；未知限制先确认，不自行编造阈值。
- 大文件或长传沿用项目取消能力，离开页面时处理取消与清理；资源释放遵循 Hook 技能，取消不能被当作上传成功。

## 交付检查

- 核对新增筛选、调整卡片、修改接口和调整布局各自的修改落点；成组配置、类型、样式与独立展示是否有明确归属，是否重复实现了已确认可用的公共能力。
- 覆盖加载、空结果、失败、重复请求以及返回该页时的行为。
- 确认复用的页面、组件、API 和路由证据；未确认的接口或权限不得写成已实现。
- 涉及上传时，验证有效文件、超限或不支持的类型、失败与取消后的状态恢复。
- 涉及启停和统计时检查极端状态下的结果一致性；适配项目已支持的主题和目标角色。区分静态检查、实际交互验证与未验证部分。
