# 国际化

涉及业务字典时读取常量技能；字典集中保存翻译键，在响应式上下文中生成文案，不在常量模块加载时固定翻译结果。

先读项目语言入口、一份语言资源和一个使用点。加载方式、语言代码和持久化以当前仓库为准，不从其他项目拷贝。

## 文案

- 用户可见文本使用既有 `t`、`$t` 或封装入口；不要再创建并行的 i18n 实例。
- 按已有层级和 key 命名新增词条，在项目支持的每份语言文件补同一 key；占位符和插值沿用相邻文案。
- 不在可本地化界面硬编码业务文案。

## 切换与回退

- 语言检测、默认语言、后备语言和持久化属于入口能力；仅在需求明确时改，并确认刷新、未知语言和缺失翻译的行为。
- 避免在页面中散落 `locale === ...` 的业务分支；显示差异放在项目既有多语言边界。

## 交付检查

- 每个新增 key 的默认语言与目标语言完整，插值和缺失 key 回退正确。
- 验证切换后重渲染、日期/数字格式以及语言选择是否按项目策略持久化。
