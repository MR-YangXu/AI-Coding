# 管理后台场景

只对后台功能使用。读哪些文件、是否再打开其他技能，以基础规则的阅读预算为准。混合项目不把本技能套到 H5 或其他页面。

## 复用

- 搜索、表格、上传、抽屉使用档案或相邻后台页里已有的组件，通过配置接入。卡片网格可以复用查询能力，不必改成表格。
- 搜索核对字段类型、选项、默认值、提交和重置。放弃复用要指出事件或布局上的具体缺口。
- 查询、刷新和操作反馈优先用契约匹配的既有组合式函数。`usePageList` 等名称只是候选，不能从其他仓库复制导入。

## 职责

沿用当前仓库的目录和命名。简单页面不必拆文件。参考页面只学习组合方式，不照搬字段、角色和已知缺陷。

| 内容 | 落点 |
| --- | --- |
| 页面入口 | 查询条件、当前行、弹窗和操作状态；组装组件并编排事件 |
| 配置 | 成组搜索项和列放同域 `config.ts`；枚举从常量模块导入，配置不重新定义 |
| 类型 | 接口类型引用领域 API；多文件共用的展示类型才放 `types.ts` |
| 私有组件 | 卡片、详情和业务弹窗放同域 `components/`，只传最小输入和明确事件 |
| 样式 | 页面布局可放同域样式文件；组件样式跟随组件，并使用主题变量 |
| 演示数据 | 允许时放独立文件，并限制启用范围 |

初始查询和动态选项按实例创建，不修改导入的配置对象。卡片不改传入对象，也不隐式刷新父页面。

## 必须写进代码的行为

只实现本次界面里有的项：

- 筛选、排序、分页共用同一份已提交条件；筛选变化时回到第一页。正在编辑的输入和已提交条件分开；重置把输入、条件和标签一起恢复，且不污染初始配置。
- 删除到空页时回到有效页。行内启停按项防重复提交；失败保留原状态或按项目策略回滚。
- 图片地址缺失或加载失败时有占位，恢复后能重新展示。
- 批量提交的范围符合接口契约，不把当前页选择当成全部结果。破坏性确认写明对象和数量；部分成功时留下可重试项。
- 权限沿用项目已有来源，隐藏按钮不代替服务端授权。编辑失败保留输入。详情快速切换时，旧响应不能覆盖新选择。
- 统计口径未确认时标为待确认，不用演示数字充当业务规则。

静态检查和核对次数遵循基础规则的验收预算。
