# 管理后台场景

先看当前页面及同业务模块的查询、表格和权限实现。本技能补充后台交互要求；根据改动同时读取页面、API、组件或路由技能。混合项目中只对后台功能应用，不因启用此场景重构其他页面。

后台组织范例仅用于管理功能，不作为通用 Vue 或 H5 页面的目录模板。当前功能同时面向移动浏览器或 WebView，且启用了移动端场景时，再结合移动端技能处理运行环境要求。

## 复用决策

- 检索当前项目的布局、搜索、表格或卡片、上传、抽屉、主题和公共 Hook，选同类后台页作为参考。先读取组件或 Hook 的实际契约及一个调用方，再确定复用清单。
- 对搜索区分别核对字段类型、选项、默认值、提交与重置事件及布局能力；已有能力满足时通过配置接入。放弃复用须指出具体缺口，例如事件语义不匹配或无法承载所需交互；仅说“更贴近设计稿”不足以说明原因。
- 查询分页、选项加载、提交后刷新和操作反馈优先使用契约匹配的既有 Hook，页面保留业务条件、接口适配和事件编排。`usePageList`、`useSelectOptions`、`useAsyncListAction` 只是候选名称，不能从参考仓库直接复制导入、响应假设或缓存键。
- 搜索表单、列表展示与列表状态分别评估复用；卡片网格可以复用查询能力，无需改成表格。组件名、UI 库和方法名以当前项目为准，不要求每个后台都采用同一套组件。

## 页面组织

新建后台业务页按“发现当前项目能力 → 确定文件职责 → 实现业务编排 → 验证结构与交互”推进。涉及列表、选项加载或操作后刷新时，同时读取 Hook 技能。参考页面用于学习职责与组合方式，不能照搬其字段、角色、组件名和已知缺陷。

推荐分工：页面连接布局、搜索、列表与抽屉；成组配置放同域配置文件；接口类型引用领域 API；独立业务展示放同域组件；较多页面样式独立维护。沿用当前仓库的目录与命名，已有小修复无需迁移整页。

| 内容 | 后台页面中的落点与职责 |
| --- | --- |
| 页面入口 | 持有查询条件、当前行、弹窗开关和局部操作状态，组装组件并编排业务事件；数据执行机制优先复用既有能力。 |
| 配置 | 成组搜索项、默认查询和表格列放同域 `config.ts` 或 `config/`；业务枚举与字典从所属常量模块导入，页面配置只组合，不重新定义。搜索配置应承接字段声明、选项及初始值；仅抽出默认值不代表已完成表单配置化。 |
| 类型 | 参数和响应类型引用领域 API；多文件共用的页面展示类型按项目惯例放同域 `types.ts`，不重复声明接口契约。 |
| 私有组件 | 卡片、独立详情面板和业务弹窗放同域 `components/` 或项目既有位置，通过最小输入和明确事件连接页面。 |
| 样式 | 较多页面布局样式按项目惯例放同域样式文件，如 `index.scss`；组件样式跟随组件，保留作用域并使用主题变量。 |
| 演示数据 | 允许使用时放独立文件或项目演示层，并限制运行时启用范围；仅拆出 `mock.ts` 不代表正式入口已与演示隔离。 |

以下是有筛选和头像卡片的页面结构示例，各文件按实际需要创建：

```text
avatarLibrary/
├── index.vue                 页面状态、组件组装和业务事件
├── index.scss                页面布局与主题样式；沿用项目预处理器
├── types.ts                  多文件使用的页面展示类型，复用 API 类型
├── config/
│   ├── index.ts              多个配置文件的出口；简单配置无需此层
│   ├── searchForm.ts         搜索项与初始查询工厂
│   └── data.ts               状态、排序等静态选项
├── components/
│   └── AvatarCard.vue        头像展示、该项禁用态与启停事件
└── mock.ts                   仅在允许演示数据时创建并隔离启用范围
```

小页面可以使用单个 `config.ts`；没有跨文件展示类型时无需建立仅转发类型的文件。卡片专属样式跟随卡片，页面不通过大范围选择器维护子组件内部外观。初始查询和动态选项须按实例创建，不能污染导入配置。

## 三类实现范例

| 任务 | 推荐组合与职责 | 应避免的实现 |
| --- | --- | --- |
| 头像卡片页 | 复用可用的搜索与上传能力，头像卡片作为私有展示组件；页面持有查询、列表及各项提交状态，统计依据已确认口径。 | 将图片占位、模拟数据、筛选配置与全部样式混进页面；把固定库存数字当成实时统计；为复用表格组件改变卡片需求。 |
| 标准表格页 | 搜索项与列声明放同域配置；组合已有搜索、表格和分页 Hook；特殊单元格用插槽，页面连接查询与领域 API。 | 项目已有合适基建仍重复实现分页、重置与加载流程；引用另一项目才有的组件或 Hook。 |
| 带详情抽屉的页面 | 复用已有抽屉外壳，详情面板放同域组件；页面或已约定业务组件负责详情请求与状态，传入所需最小数据。 | 列表页包含整块复杂详情模板与全部内部样式；把页面业务请求塞进共享抽屉外壳；旧详情响应覆盖新选择。 |

配置里的筛选选项、展示标签与组件状态映射按各自契约定义；例如选项数组不能直接作为组件颜色类型映射，索引和值域必须匹配。

头像卡片接收展示数据和该项操作中的状态，通过有明确类型的事件传出标识与目标状态；页面负责提交、结果同步和失败反馈。卡片不修改传入对象，不隐式刷新父页面；处理图片地址缺失和加载失败两种状态。

统计和库存判断使用已确认口径；口径未知时标为未提供或待确认，不把演示数字和任意公式写成业务规则。成组指标可使用数据配置统一渲染，少量纯展示内容无需额外抽组件。

## 查询与表格

- 复用满足需求的已有搜索表单和列表能力；表格用已有表格组件，卡片网格保留卡片展示。筛选、排序、分页以同一查询条件为依据；筛选变化时按项目约定重置页码，避免旧页码造成假空结果。
- 区分正在编辑与已经提交的查询条件，按交互约定决定切换状态标签是否提交其他输入。标签选中值尽量从查询状态派生；确需独立维护时，搜索与重置须同步更新，并保持值在合法选项内。
- 删除最后一页数据后，按总数与分页约定回到有效页；从详情返回时沿用已有查询与滚动恢复方式。
- 列宽、固定列、溢出展示与操作入口沿用项目组件能力，验证窄窗口和长内容；仅在数据量或实测瓶颈需要时采用虚拟表格。
- 行内启停按项维护提交状态，失败时保留原状态或按策略回滚，并同步受影响的列表、详情和统计。

## 批量操作与权限

- 明确选择范围是当前页、跨页已选项还是全部查询结果；提交的标识或筛选条件必须符合接口契约，不能把当前页选择默认解释为全部结果。
- 筛选、翻页或权限变化后，按项目策略清理或重新校验选择。涉及破坏性操作时，确认文案须说明实际对象与数量。
- 部分成功时区分成功项与失败项，保留可重试对象；不要把整个批次显示为成功，或无依据重试已成功的写操作。
- 页面、按钮与接口权限使用同一已确认的权限来源；隐藏按钮不能替代后端授权，权限失败按现有交互处理。

## 编辑流程

- 未保存修改的离开提示、保存后列表刷新及详情同步遵循项目已有模式；没有相关需求时不另建草稿系统。
- 若接口支持版本号或并发冲突检测，按契约提示冲突并保留用户输入，不静默覆盖其他人的更新。

## 交付检查

实现前按本次改动选择以下行为并确定预期，实现后执行同样操作核对结果。该表仅用于后台相关功能，不要求普通 Vue 或 H5 页面逐项执行；缺少相关功能时标为不适用。

| 行为 | 操作与异常场景 | 验收结果 |
| --- | --- | --- |
| 搜索 | 修改关键词、排序或其他筛选后提交；异步查询时让旧请求晚返回。 | 结果对应已提交条件，旧结果不能覆盖新结果。 |
| 重置 | 修改多个条件、切到非默认标签后重置，再次进入页面。 | 输入、已提交条件、标签和列表恢复一致的默认状态，初始配置未被污染。 |
| 标签切换 | 保留尚未提交的输入，再切换状态标签。 | 按事先确定的策略决定是否同时提交输入；标签选中值、查询条件和列表一致。 |
| 启停 | 连续操作同一项、操作其他项，并分别模拟成功与失败。 | 同一项防重复提交，其他项按约定可操作；成功同步相关展示，失败保留原值或按策略回滚。 |
| 图片失败 | 地址为空、返回错误，再换成可用地址。 | 有明确占位，布局稳定，资源恢复后能正常展示。 |
| 空态与统计 | 无匹配结果、全部停用、操作失败。 | 空态合理，列表、标签计数和统计使用已确认口径，不自行编造库存公式。 |

- 说明参考页面和实际复用能力；检查新增筛选、调整卡片或单元格、修改接口与调整布局各自的修改落点。检查页面是否保留业务编排、组件是否通过明确输入与事件协作。
- 涉及分页时还须验证筛选后的页码、删除后的有效页和返回列表的状态。
- 涉及批量操作时验证跨页选择、筛选变化、部分失败和权限变化。
- 涉及编辑时验证保存失败保留输入，以及项目已约定的未保存离开、并发冲突行为。
- 涉及详情时验证快速切换对象后的结果归属；主题与角色验证以当前项目支持范围为准。
- 如实报告静态检查与实际行为验证；类型检查缺失或失败须单独说明，ESLint 和构建通过不能代替类型检查。上述结构和业务检查由实现与审查完成，不能声称 CLI 已自动证明页面符合要求。
