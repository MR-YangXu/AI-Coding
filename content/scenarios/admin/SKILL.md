# 管理后台场景

只对后台功能使用。读哪些文件、是否再打开其他技能，以基础规则的阅读预算为准。混合项目不把本技能套到 H5 或其他页面。

## 复用

- 搜索、表格、上传、抽屉使用档案或相邻后台页里已有的组件，通过配置接入。卡片网格可以复用查询能力，不必改成表格。
- 搜索核对字段类型、选项、默认值、提交和重置。放弃复用要指出事件或布局上的具体缺口。
- 查询、刷新和操作反馈优先用契约匹配的既有{{logic}}。`usePageList` 等名称只是候选，不能从其他仓库复制导入。
- 第一层业务 Tab 沿用项目已有 Tab 组件。业务弹窗按语义独立成组件，打开方式与相邻后台页一致。

### 缺少后台基础能力时

先核实 profile 与实际源码；档案未登记不等于能力不存在。已有实现满足需求时直接复用。项目确实缺少当前任务需要的组件或逻辑时，可执行 `ai-code add admin --only NewTable,usePageList --dry-run --json` 查看源码添加计划，再按实际缺口选择 `--only` 执行添加；整套接入使用 `ai-code add admin`。

命令沿用已保存的框架和语言：Vue 3 使用 Element Plus，React 使用 Ant Design，Vue 2 使用 Element UI。依赖缺失或与项目 UI 选择不兼容时，报告具体差异，不自行替换已有 UI 体系。组件、逻辑、工具分别合入公共目录；Vue 2 的逻辑能力实际生成 createPageList 等选项式辅助函数，不使用组合式 Hook。

同名冲突必须明确选择替换、不复制或重命名；不能仅凭同名判断接口兼容。跳过依赖会连带跳过依赖它的待安装项，重命名只改本批源码的引用。非交互用 `--conflict replace|skip|rename` 表达已确定的选择，不为让命令通过而擅自覆盖项目文件。

完成后依据命令报告核对实际文件与调用契约，提示把真实入口、用途和参考页面补充到 `.ai-code/profile.md`。源码归项目维护，规则同步不覆盖；不要把未安装项写成可用能力。接入示例和样式要求见命令输出的对应技术栈 README，只在需要接入该工具集时阅读。

## 职责

新建页的目录以项目档案里写明的文件树为准。档案没有写目录时，才沿用相邻后台页。不要把已有页面改成档案里的目录。简单页面不必拆文件。参考页面只学习组合方式，不照搬字段、角色和已知缺陷。

新建筛选加列表的页面时，先按该目录落文件，再补字段和交互。没有的文件不创建。页面编排查询、分页和操作，筛选与列表分开。选项、标签色和页面说明放在档案约定的展示配置里。业务码值沿用模块已有常量，页面里不再复制一份。接口契约引用领域 API。页面样式只负责布局，组件样式跟随组件并使用主题变量。初始查询和动态选项按实例创建，不修改导入的配置对象。展示派生遵循所选框架能力，渲染中不编排请求或多步骤业务副作用。卡片不改传入对象，也不隐式刷新父页面。演示数据仅在允许时另放，并限制启用范围。

## 必须写进代码的行为

只实现本次界面里有的项：

- 筛选、排序、分页共用同一份已提交条件；筛选变化时回到第一页。正在编辑的输入和已提交条件分开；重置把输入、条件和标签一起恢复，且不污染初始配置。
- 删除到空页时回到有效页。行内启停按项防重复提交；失败保留原状态或按项目策略回滚。
- 图片地址缺失或加载失败时有占位，恢复后能重新展示。
- 批量提交的范围符合接口契约，不把当前页选择当成全部结果。破坏性确认写明对象和数量；部分成功时留下可重试项。
- 权限沿用项目已有来源，隐藏按钮不代替服务端授权。编辑失败保留输入。详情快速切换时，旧响应不能覆盖新选择。
- 统计口径未确认时标为待确认，不用演示数字充当业务规则。

静态检查和核对次数遵循基础规则的验收预算。
