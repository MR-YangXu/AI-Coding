# 管理后台场景

先看当前页面及同业务模块的查询、表格和权限实现。本技能补充后台交互要求；根据改动同时读取页面、API、组件或路由技能。混合项目中只对后台功能应用，不因启用此场景重构其他页面。

## 页面组织

新建后台业务页按“发现当前项目能力 → 确定文件职责 → 实现业务编排 → 验证结构与交互”推进。涉及列表、选项加载或操作后刷新时，同时读取 Hook 技能。参考页面用于学习职责与组合方式，不能照搬其字段、角色、组件名和已知缺陷。

推荐分工：页面连接布局、搜索、列表与抽屉；成组配置放同域配置文件；接口类型引用领域 API；独立业务展示放同域组件；较多页面样式独立维护。沿用当前仓库的目录与命名，已有小修复无需迁移整页。

以下是有筛选和头像卡片的页面结构示例，各文件按实际需要创建：

```text
avatarLibrary/
├── index.vue                 页面状态、组件组装和业务事件
├── index.scss                页面布局与主题样式；沿用项目预处理器
├── types.ts                  多文件使用的页面展示类型，复用 API 类型
├── config/
│   ├── index.ts              多个配置文件的出口；简单配置无需此层
│   ├── searchForm.ts         搜索项与初始查询工厂
│   └── data.ts               状态、排序等静态选项
├── components/
│   └── AvatarCard.vue        头像展示、该项禁用态与启停事件
└── mock.ts                   仅在允许演示数据时创建并隔离启用范围
```

小页面可以使用单个 `config.ts`；没有跨文件展示类型时无需建立仅转发类型的文件。卡片专属样式跟随卡片，页面不通过大范围选择器维护子组件内部外观。初始查询和动态选项须按实例创建，不能污染导入配置。

## 三类实现范例

| 任务 | 推荐组合与职责 | 应避免的实现 |
| --- | --- | --- |
| 头像卡片页 | 复用可用的搜索与上传能力，头像卡片作为私有展示组件；页面持有查询、列表及各项提交状态，统计依据已确认口径。 | 将图片占位、模拟数据、筛选配置与全部样式混进页面；把固定库存数字当成实时统计；为复用表格组件改变卡片需求。 |
| 标准表格页 | 搜索项与列声明放同域配置；组合已有搜索、表格和分页 Hook；特殊单元格用插槽，页面连接查询与领域 API。 | 项目已有合适基建仍重复实现分页、重置与加载流程；引用另一项目才有的组件或 Hook。 |
| 带详情抽屉的页面 | 复用已有抽屉外壳，详情面板放同域组件；页面或已约定业务组件负责详情请求与状态，传入所需最小数据。 | 列表页包含整块复杂详情模板与全部内部样式；把页面业务请求塞进共享抽屉外壳；旧详情响应覆盖新选择。 |

配置里的筛选选项、展示标签与组件状态映射按各自契约定义；例如选项数组不能直接作为组件颜色类型映射，索引和值域必须匹配。

## 查询与表格

- 复用满足需求的已有搜索表单和列表能力；表格用已有表格组件，卡片网格保留卡片展示。筛选、排序、分页以同一查询条件为依据；筛选变化时按项目约定重置页码，避免旧页码造成假空结果。
- 删除最后一页数据后，按总数与分页约定回到有效页；从详情返回时沿用已有查询与滚动恢复方式。
- 列宽、固定列、溢出展示与操作入口沿用项目组件能力，验证窄窗口和长内容；仅在数据量或实测瓶颈需要时采用虚拟表格。

## 批量操作与权限

- 明确选择范围是当前页、跨页已选项还是全部查询结果；提交的标识或筛选条件必须符合接口契约，不能把当前页选择默认解释为全部结果。
- 筛选、翻页或权限变化后，按项目策略清理或重新校验选择。涉及破坏性操作时，确认文案须说明实际对象与数量。
- 部分成功时区分成功项与失败项，保留可重试对象；不要把整个批次显示为成功，或无依据重试已成功的写操作。
- 页面、按钮与接口权限使用同一已确认的权限来源；隐藏按钮不能替代后端授权，权限失败按现有交互处理。

## 编辑流程

- 未保存修改的离开提示、保存后列表刷新及详情同步遵循项目已有模式；没有相关需求时不另建草稿系统。
- 若接口支持版本号或并发冲突检测，按契约提示冲突并保留用户输入，不静默覆盖其他人的更新。

## 交付检查

- 说明参考页面和实际复用能力；检查新增筛选、调整卡片或单元格、修改接口与调整布局各自的修改落点。检查页面是否保留业务编排、组件是否通过明确输入与事件协作。
- 涉及查询时验证筛选后页码、删除后的有效页和返回列表的状态。
- 涉及批量操作时验证跨页选择、筛选变化、部分失败和权限变化。
- 涉及编辑时验证保存失败保留输入，以及项目已约定的未保存离开、并发冲突行为。
- 涉及详情时验证快速切换对象后的结果归属；涉及卡片与统计时验证全部停用、空列表和操作失败后的状态一致性。主题与角色验证以当前项目支持范围为准。
- 如实报告静态检查与实际行为验证；上述结构和业务检查由实现与审查完成，不能声称 CLI 已自动证明页面符合要求。
