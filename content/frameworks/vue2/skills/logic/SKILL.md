# 逻辑复用

先查已有实现与一个调用方；函数名相同不代表契约相同。组件专属业务决策留在组件，纯转换优先纯函数，请求走已有 API 层。

- 仅在多个调用方、明确独立的复杂流程或需要统一资源管理时抽取；不要为缩短页面创建隐藏整页状态的混入。
- 通用机制通过参数、返回值及回调连接调用方，明确错误与取消语义。需要可变状态时按调用创建，不能把模块级对象共享给所有组件。
- 不默认新增 mixin；维护现有 mixin 时核对 data、methods、computed、watch 命名冲突、隐式 this 依赖及生命周期合并顺序。
- 明确监听、定时器和请求由谁创建、谁清理；清理可重复调用，keep-alive 的激活与停用不累积资源。
- 请求竞态和 loading 归属于有效执行，旧执行结束不能覆盖新结果或提前关闭 loading。
- 验收已有调用方兼容性、失败与取消、重新进入、重复调用及多个实例状态隔离。
