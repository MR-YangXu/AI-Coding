# 路由

以项目已安装版本和现有路由入口为准，常见 Vue Router 3 与 Vue Router 4 的接口不能混用。不迁移路由目录或权限体系。

- 新入口沿用相邻路由的懒加载、name、meta、菜单与权限约定；只有需求需要入口时才新增路由。
- 沿用项目守卫风格；使用 next 时每条分支只完成一次导航，不重复 next 或遗漏结束路径。
- params、query、权限键以源码与契约为准，外部输入先校验类型、缺失及多值情况再用于请求。
- 登录 redirect 及外链目标使用项目允许范围校验，拒绝不被允许的协议、来源和 `//host` 形式，不能直接信任外部输入。
- keep-alive、动态权限、标签页变更须核对组件名称、缓存键、菜单和注销流程；同组件参数变化是否重新加载沿用既有约定。
- 验证注册入口、非法参数、安全回跳和实际需要的状态恢复，报告未验证路径。
