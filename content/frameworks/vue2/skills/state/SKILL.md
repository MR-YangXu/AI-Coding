# 共享状态

仅跨路由或跨模块共享的数据进入 Store；页面查询、分页、表单、弹窗与局部 loading 留在页面。

- 先读项目已有状态入口与调用方，沿用已安装方案。Vuex 模块的 state、getters、mutations、actions 各有职责，不直接套用 Pinia 命名或引入另一套库。
- Vuex 异步流程放 action，同步状态修改按项目 mutation 约定执行；namespaced 模块核对真实访问路径。
- 可复用或动态注册模块用 state 工厂保证隔离；新增响应式属性遵循 Vue 2 限制。Store 不存 DOM、组件实例或整页引用。
- 持久化只覆盖实际需要跨会话恢复的数据，遵循现有敏感数据边界。
- 登录、登出、切站点和权限变更同步检查相关菜单与缓存；旧请求失效，重置创建干净状态。
- 验证跨页面消费者、持久化恢复、并发请求、权限过期及重置，不改变无关页面状态。
