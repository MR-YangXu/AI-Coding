# 组件

先核实候选组件的契约及调用方。能配置或兼容扩展时优先复用；私有组件就近放置，确有跨业务复用时再提升到共享目录。

- props 向下传递，通过语义事件通知父级；不直接修改 props 及其对象字段。对象和数组默认值使用工厂，组件 `data()` 按实例创建。
- 默认 v-model 使用 value/input；已有 `model` 配置时遵循其 prop/event。`.sync` 对应 `update:属性名`，不要套用 Vue 3 的 modelValue、defineModel、defineExpose。
- 结构使用插槽，向插槽使用方传数据采用作用域插槽；沿用项目已有 slot/slot-scope 或 v-slot 写法，不整体迁移。
- `inheritAttrs`、`$attrs` 和 `$listeners` 按实际目标元素透传，避免双重事件调用；不能把所有属性、监听器无差别绑定到多个层级。
- props 是初始值还是持续受控值必须明确；派生展示用 computed，需要可编辑副本时明确同步和提交时机。
- UI 基础组件不请求业务 API、不依赖业务 Store；业务包装组件明确 loading、错误和完成事件。副作用在销毁时清理，缓存组件另查停用语义。
- 组件样式跟随组件，沿用样式作用域和主题；覆盖第三方样式限制选择器范围。用户可控 HTML 必须使用项目已有净化方案。
- 保留标签、键盘与焦点语义；弹窗关闭后恢复焦点。验证默认值、事件名称、父级更新、多个实例隔离及失败恢复。
