# 国际化

读取已有语言入口、一份语言资源及一个调用方；沿用实际版本的 `$t`、`$tc` 或封装入口，不引入另一套实例。

- 新 key 按已有层级命名，在项目支持的每种语言中补齐，插值和复数规则沿用当前版本。
- 字典保存翻译键，展示在 computed、模板或已有响应式机制中生成；不能在常量模块加载时固定翻译结果。
- 默认语言、回退和持久化仅在任务要求时修改；处理未知语言及缺失 key，不在页面散落 locale 分支。
- 日期与数字通过项目已有格式化入口，切换语言后文字、选项和格式同步更新。
- 验证插值、缺失词条回退、刷新恢复与语言切换，记录未完成的翻译。
