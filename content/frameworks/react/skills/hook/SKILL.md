# React Hook

先核实已有 Hook 与调用方；仅在复用状态、副作用或明确独立的复杂流程时提取，不把整页业务搬入 usePage。

- 使用 use 前缀，组件或 Hook 顶层调用；不在条件、循环、普通回调或异步函数中调用 Hook。
- 输入、返回值及回调最小且明确；路由、弹窗、业务请求依赖通过接口或项目既有边界表达，不隐藏页面决策。
- 每次调用默认隔离状态，共享需求通过已有状态或缓存机制完成，不依赖无意共享的模块变量。
- Effect 同步外部系统，依赖包含实际读取的响应式值；不能关闭依赖检查来掩盖闭包旧值。能直接计算的派生值留在渲染中，用户动作留在事件处理器。
- 依赖旧状态更新用函数式 setter；ref 适合保存不参与渲染的句柄和最新执行标识，不用 ref 绕过应该触发渲染的状态。
- 监听器、定时器、观察器、订阅及请求都有清理；保证严格模式的设置→清理→重新设置可正确运行。
- 每次请求有有效性标识，旧结果、旧失败和 finally 都不能覆盖新执行；取消请求不表示服务端撤销写操作。
- useMemo/useCallback 只服务实际性能或稳定引用契约，不能作为程序正确性的前提。
- 验证依赖变化、快速重复调用、失败、卸载、重新挂载和多个实例；不自动为每个 Hook 新增测试框架。
