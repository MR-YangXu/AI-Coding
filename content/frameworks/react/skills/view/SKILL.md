# 页面

先定位 profile、相邻页面及现有路由与请求入口；目录沿用项目，不因使用 React 就强制创建 pages、hooks 或 services。

- 页面负责组合组件、局部交互状态与业务事件。复用已有组件、请求库和 Hook；API 契约归请求模块，跨页面共享才进入已有状态方案。
- 渲染保持纯净，不在组件函数执行期间请求接口或修改外部状态。初始可变状态按实例创建，编辑数据不污染导入配置或重置基准。
- state 不可变更新，依赖上一次值时使用函数式更新；可从 props/state 直接算出的值在渲染中派生，不用 Effect 复制第二份状态。
- 受控表单处理空值，避免受控与非受控切换；提交条件和正在编辑条件按需求明确区分，列表 key 使用稳定身份。
- 事件处理用户操作，Effect 同步外部系统；已有路由 loader 或请求缓存能力满足需求时复用，不重复建立请求缓存。
- 异步流程处理 loading、空结果、失败、防重、过期响应和卸载；关闭旧请求的 loading 不能影响新请求。失败不回退演示数据。
- 提交与外部副作用不依赖 Effect 重复触发；保持严格模式下清理和重新订阅正确。
- 交付验证当前功能的状态更新、快速切换、重置、失败与恢复，报告复用来源和实际检查结果。
