# 路由

读取项目实际路由库、版本和入口，沿用现有声明方式。React Router 不同版本的组件、Hook、loader 接口不能混用，不自动切换为文件路由框架。

- 新入口按相邻模块的布局、懒加载、菜单与权限注册；只在需求需要入口时增加路由。
- params、search、返回状态和权限来自实际契约；外部值先处理缺失、多值、类型与格式，再用于查询或请求。
- 登录回跳和外链验证允许路径、协议与来源，不直接消费外部 redirect；包含 `//host` 的目标也要处理。
- 沿用现有授权组件或 loader 边界，隐藏按钮不能替代服务端授权。
- 参数变化、嵌套路由切换与返回恢复按当前模式处理；Effect、loader 和请求缓存不得重复发起同一加载。
- 验证路由注册、非法参数、安全回跳及需要的状态恢复，版本专属功能先核实可用性。
