# 国际化

先读项目已有国际化入口、一份语言资源和调用方，沿用 react-i18next、react-intl 或实际封装，不创建第二个实例。

- 组件通过现有 Hook/Context 订阅语言变化，遵守 Hooks 调用规则；不要在普通常量模块调用 Hook。
- 常量字典保存翻译键，在渲染或正确依赖语言的派生逻辑中生成文案；不能在模块加载时固定翻译结果。
- 新 key、命名空间、插值与复数规则沿用项目，在所有支持的语言资源中补齐。
- 默认语言、回退、异步资源和持久化仅按需求修改；未知语言和缺失 key 有既有回退，不散落 locale 业务分支。
- 使用项目日期数字格式化入口，验证语言切换后组件、选项与缓存文案更新，记录缺失翻译及未验证路径。
