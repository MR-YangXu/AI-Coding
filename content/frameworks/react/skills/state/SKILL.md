# 共享状态

先判断数据归属：组件局部交互留在局部，共享客户端状态使用现有 Context/状态库，服务端数据优先使用已有请求缓存。

- 不为了页面查询、分页、表单和弹窗新增全局 Store。避免同一数据在请求缓存和 Store 中重复维护。
- 沿用项目现有 Redux、Zustand、Context 或其他方案，不引入并行库。action、selector 和不可变更新按该方案的契约实现。
- Context 的 provider 作用域应覆盖实际消费者；减少无关字段更新引起的重渲染，但不为所有值机械增加缓存。
- Store 不存 DOM、组件实例或短期页面引用；默认值和重置基准不能共享可变对象。
- 登录、登出、切租户同时处理请求缓存、持久化、路由和权限；旧请求结果必须失效。
- 持久化仅存实际需要恢复的数据，敏感字段遵守现有边界。验证消费者一致性、并发、重置及刷新恢复。
