# 组件

先核实已有组件输入、children（子内容）、回调和调用方；能力满足时复用，存在小缺口时评估兼容扩展。私有组件放功能附近，确需跨业务复用时再提升。

- 渲染保持纯净，不修改 props 或 state。结构用 children 或项目已有渲染插槽约定，动作通过语义回调传递，不把 Vue emits 或 v-model 套入 React。
- 明确受控与非受控模式，value 与 onChange 等契约成对维护；仅作初始值的 defaultValue 不承诺后续同步。
- 可直接派生的展示值不保存第二份 state；更新依赖旧值时用函数式更新。列表 key 必须表达稳定身份，不能用随机数掩盖状态复用问题。
- Hooks 顶层调用，不放条件或循环；不要在父组件渲染函数中定义需要保持身份的子组件类型。
- UI 基础组件不绑定业务 API/Store；业务包装明确加载、错误及完成回调。副作用按 Hook 规则清理。
- DOM 属性只传到合理目标，避免无差别展开业务 props。命令式 ref 仅在确需聚焦或外部控制时使用，具体 API 先核实 React 版本。
- 沿用项目样式与主题方案，抽取组件时带走专属样式；富文本用项目已有净化边界，不能直接注入用户可控 HTML。
- 保留 label、键盘、可访问名称和焦点管理，弹窗关闭恢复焦点。memo 等缓存只用于已确认的性能需要。
- 验证父级更新、回调、禁用与空值、实例隔离和失败恢复；契约声明遵循所选语言规则。
