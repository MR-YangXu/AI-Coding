# AI 编码基本规则

## 阅读预算

有 `.ai-code/profile.md` 时，它是唯一的项目入口。只读当前场景的推荐能力、源码入口、参考实现、可借鉴部分和禁止效仿项，再打开档案点名的一个路由模块、一个参考页面的前 120 行。组件或逻辑函数的契约用搜索定位输入、输出和一处调用，不整文件加载。档案不代替组件契约，导入和字段仍以当前仓库源码为准。

没有档案时，只读一个相邻路由模块和一个同类页面的前 120 行，交付时注明缺口。不为本次任务新建档案，也不去安装包里翻模板。不派子代理，不做全库探索，不读 `docs/`、`.ai-code/README.md`、事实索引或其他仓库的技能。本仓库只使用已安装的 `ai-code-*` 技能，不读取 `company-vue-*` 或其他规范全文。

技能全文只读一次，会话里已读过的不重复打开。按已安装的技能入口决定读哪一份；不逐项加载全部技能。

检索先从公共与业务入口、现有导入开始；入口不明、未找到匹配定义或涉及跨模块影响时，可按业务名称和符号定向搜索全项目，先看路径与命中片段，再补读相关定义和调用方。这属于必要检索，不是无目的的全库探索。证据足以决定复用、归属和影响范围后停止；多个技能共用已核实且仍有效的结果，不重复执行相同检索和检查。

具体技能入口由当前技术栈生成。页面先读页面技能，后台或 H5 交互再叠加对应场景；局部修复不必加载整套场景。

局部修复只读被改文件和它的直接调用约定，不按上表补读场景技能。仅要求审查时，报告有证据的问题、位置、触发条件和影响，不改代码。

## 实现约束

- 以需求的目标、范围和验收标准为准。关键事实无法确认时标明待确认项，继续完成不依赖它的工作。不编造仓库中不存在的模块、API、依赖或字段。
- 优先复用档案或相邻实现中的组件、请求层和工具。不复用时说明候选路径和具体缺口；“更简单”或“更贴近设计稿”不能作为理由。无既有先例不新增依赖。
- 同一业务语义只有一份常量和字典，使用处导入。页面配置不重新定义枚举。只在本次改动新增或修改码值时才读常量技能，并按“公共导出 → 当前业务入口 → 相关定义”检索；已核实且未变化的内容不重读。
- 只改任务范围。不顺手重构，不用空 catch 或关闭检查来掩盖问题。
- 异步交互在代码里闭合 loading、空结果、失败、重复提交和过期响应。
- “接口未定”仅指目标业务既无已确认 URL，也无现有请求函数；字段、权限或响应层级不明、请求失败均不算接口未定。有请求函数就直接复用并调用；仅有 URL 时按已确认契约在现有请求层补齐请求函数。未确认项标为待确认，不猜参数或返回结构，不因此改用模拟数据。
- 请求失败沿用项目错误处理并明确反馈；禁止在页面 `catch` 或其他失败分支回退本地数据、替换为演示列表，或以空列表掩盖失败。
- 仅在接口未定且任务明确允许模拟时，使用独立的 `mock.{{ext}}`（模拟接口），不用 `demo.{{ext}}` 或页面内嵌演示数据。函数名、参数、异步行为和调用方所见的返回层级须遵循已确认的接口约定，使后续可通过替换 `import`（导入）接入真实 API；未确认的契约保留待确认，不自行编造。交付时标明未联调；只改内存不能写成保存成功。
- 页面持有本功能的查询和操作状态。请求契约留在 API 层，跨路由共享才进 Store，私有展示放同域组件。需要独立维护或被多个文件使用时再拆文件。

## 验收预算

- 默认只对本次改动文件运行项目已有的 lint。输出只留摘要；失败时只看报错位置。本次引入的错误修复后进行必要复验；已确认的历史或环境故障在原因未变化时不原样重跑，不把完整日志读回对话。
- 行为只核对本次界面实际有的路径，每条一次：搜索与重置一致、筛选后回到第一页、末页删除回到有效页、启停失败回滚、非法上传被拒绝。看代码路径或做一次操作即可。不写浏览器脚本，不反复截图，不逐项手测刷新、返回和无权限，除非用户要求。
- 交付说明复用了哪一页、哪一个组件，以及 lint 的实际结果。未运行的检查和未联调的接口单独列出。

## 其他

- 不提交密钥、真实用户数据或含秘密的环境文件。日志和上报不输出令牌、完整 Cookie 或未脱敏个人信息。
- 涉及不可逆操作时先确认范围。
